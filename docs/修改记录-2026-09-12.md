# 修改记录（2026-09-12）

## 1. 生成任务目录隔离

- 新增任务运行上下文，将素材清单、素材库存、参考视频报告、镜头分析、结构分析、个人知识、生成方案和最终视频统一写入当前任务目录。
- Web 正式链路不再读写 `video_analysis_demo`、固定素材库存或 `beijing_materials.json` 等共享文件。
- 素材分析、编辑迁移和智能生成脚本新增显式输入/输出参数，避免并发任务互相覆盖。

## 2. 复用视频基因分析报告

- 项目新增 `gene_id`，创建项目时会保留所选视频基因的关联，不再只复制一份视频后丢失来源。
- 现有 SQLite 数据库启动时自动补充 `project.gene_id` 列和索引。
- 从已完成基因创建的项目会直接复用基因报告，并在任务目录内拆分出流水线所需的镜头与结构文件，不重复调用视觉模型。

## 3. 轻量编辑迁移真正无需 API

- `editing_transfer` 不再先执行视觉素材分析和视频模型分析。
- 无基因报告时，直接使用本地场景切分、参考视频音频和节拍检测构建剪辑结构。
- 有基因报告时复用报告提升结构精度，但仍不会调用模型 API。
- 启动剪辑迁移子进程时显式清空视觉和文本模型凭据，防止意外请求。
- 项目创建页明确区分“轻量编辑迁移（无需 API）”和“智能生成流水线（需要 API）”。

## 4. 去除演示主题硬编码

- 正式素材分析、编辑迁移和智能生成脚本不再固定使用北京旅行主题、标题、字幕或素材描述。
- 标题、字幕兜底和方案偏好全部根据项目主题动态生成。

## 5. 任务校验修正

- 视频分析任务只要求参考视频。
- 素材分析任务只要求图片。
- 完整生成任务要求参考视频和图片。
- 尚未接通的独立“生成方案”和“渲染”任务会直接返回明确错误，不再创建必然失败的任务。

## 6. 验证结果

- 后端测试：19 项通过；新增任务隔离、基因关联、报告复用输入、轻量清单格式、无 API 主链路、草案编辑校验和两阶段队列测试。
- 引擎测试：61 项通过；新增本地规则结构、主题动态化、智能生成偏好和确认渲染库存测试。
- 前端 `lint` 通过，生产构建通过。
- SQLite 迁移实测成功，`project` 表已包含 `gene_id`。
- 前后端已重启并加载最新代码：`http://127.0.0.1:8000/docs` 与 `http://127.0.0.1:5173` 均返回 200。

## 7. 当前边界

- P0 主链路可靠性改造已完成。
- 智能生成路线仍需要视觉模型和文本模型；轻量编辑迁移不需要。
- 本机当前没有可用于完整渲染验收的项目素材，因此真实 Remotion 成片仍需用一组参考视频和图片做一次人工验收。

## 8. 分镜确认台

- 完整生成任务拆分为 `prepare → awaiting_confirmation → render` 三个阶段：先生成草案并暂停，用户确认后才进入渲染队列。
- 任务表新增 `workflow_stage`、`scheme_path` 和 `draft_revision`，现有数据库启动时自动迁移。
- 新增分镜草案查询、保存、确认渲染和素材预览接口，并保持项目/用户归属校验。
- 草案编辑只允许使用当前任务库存中的素材；时长限制为单镜 0.2～30 秒、总长不超过 600 秒，字幕不超过 200 字，转场限定为渲染器支持的类型。
- 草案使用版本号避免多个页面同时编辑时静默覆盖；保存采用任务目录内原子替换。
- 确认台支持标题编辑、更换素材、修改时长/字幕/转场、上下排序和删除分镜，并实时计算镜头数与总时长。
- 确认后的通用渲染脚本只读取已保存草案和任务素材；如方案沿用参考视频 BGM，会在渲染阶段重新提取音频，全程不调用 LLM。
- 任务时间线新增“生成分镜”和“分镜确认”，历史任务列表新增“等待确认”状态。
- 后端 19 项、引擎 61 项测试全部通过；前端 lint 和生产构建通过。
