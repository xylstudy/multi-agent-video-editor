# 修改记录 — 2026-09-06

> 本次工作内容：把多智能体视频编辑引擎升级为「Reference-guided 结构迁移 Agent」——新增结构基因（Gene）+ 剪辑技能（Skill）双层，核心原则 **Gene 决定「迁移什么」，Skill 决定「怎么迁移好」**；在保留既有 `参考视频 → Analyst → 结构/Gene JSON → Planner` 链路的前提下，实现结构迁移（Structure Transfer）而非内容复制，并补足双维度审核与可溯源方案。

---

## 一、需求与根因

原系统 Analyst 产出的 `VideoStructure` 记录的是**原片内容**（逐镜头描述/技法），Planner 直接照着内容做方案，导致迁移时倾向「复制原片物体」——遇到「参考是航拍地标、用户只有普通照片」就无解或硬凑。缺三样东西：

1. 一个表达**结构功能**（这镜承担什么功能/节奏/情绪，和上一镜什么关系）而非具体物体的中间表示；
2. 一份**跨任务复用**的剪辑决策知识，帮 Planner 在用户素材条件下把结构剪好，但又不能喧宾夺主；
3. 审核时区分「迁移得不像 Reference」和「像但剪得不好」两类不同性质的问题。

目标：按 8 项要求 + 6 个验收用例（Case 1~6）落地，全部为可运行代码，并跑通测试、更新文档。

## 二、语义设计

- **Gene（结构基因）**：当前参考视频专属，硬约束为主。`ShotGene` 表达 `function`（hook/establishing/climax/closing/…）、`semantic_role`、`rhythm_role`、`emotion_role`、`relation_to_previous`、`visual_requirement`（功能性画面要求）、`duration_ratio`、`importance`（critical/high/medium/low）、`hard_constraints`/`soft_preferences`。`build_gene()` 是纯函数，把 Analyst 的逐镜头分析 + 全局结构分析映射为基因（hook→critical、climax/establishing/closing→high、写入「保持高潮位置约全片 N%」等硬约束）。
- **Skill（剪辑技能）**：跨任务长期复用，软策略为主。`skills/video-editing/SKILL.md` 只放定位/使用时机/路由规则/优先级，真实知识在 7 个 `references/*.md`（hook/rhythm/transition/emotion/material-matching/structure-adaptation/subtitle，各含 适用条件/不适用条件/推荐策略/例子）。
- **优先级**（贯穿 Planner 与 Reviewer）：`用户显式要求 > Reference Gene 硬约束 > Editing Skill > 模型自由发挥`。
- **可溯源**：`VideoScheme` 逐镜带 `structure_function/gene_shot_index/skill_refs/adaptation`，方案级带 `gene_refs/skill_refs_used/adaptation_log`，形成 `Gene → Material → Skill → Adaptation` 链路；沿用既有 `knowledge_refs`，未重设计。

## 三、关键决策

1. **gene.py 自包含**：`models/gene.py` 不 import `video_structure`，避免循环依赖；`video_structure.py` 反向 import `gene`，把 `gene` 作为 `VideoStructure` 的可选字段挂上去。
2. **渐进式披露，不上 RAG/向量库**：`SkillRouter` 用三条确定性路径（`route_for_stage` 阶段触发 / `route_for_shot` 镜头功能触发 / `route_for_gene` 整条 Gene 汇总），`route_by_llm` 仅作语义兜底。恒含 `structure-adaptation`；存在 `establishing` 时强制 `material-matching`（功能级素材迁移）。
3. **Planner prompt 改造**：Gene 单独成段作核心约束，Skill 按需注入（带 `===== Skill 参考：xxx.md =====` 标题），移除旧的全量 `techniques_summary` 注入；新增决策优先级块 + 「Structure Transfer 不是 Content Copy」指引。
4. **Reviewer 双维度**：A 组 Fidelity（A1~A6：hook 结构/镜头时长关系/节奏曲线/情绪弧线/高潮 Ending 位置/核心镜头功能）+ B 组 Quality（B1~B6：素材匹配/转场/节奏自然度/情绪连贯/字幕包装/素材覆盖），输出 `feedback_type ∈ {fidelity, quality, mixed}`；fidelity 问题回 Planner 恢复 Gene，quality 问题在不破坏 Gene 下优化。保留旧 `scores` 扁平字段做向后兼容。
5. **向后兼容**：LangGraph / `ViralEngineState` / Analyst / MaterialManager / Planner / VideoScheme / Renderer / Assembler / Reviewer / Knowledge / Trace 全部沿用；`_generate_scheme`/`_review_scheme` 只追加可选参数，旧脚本（`run_scheme_generation.py`/`run_pipeline_e2e.py`/`run_beijing_pipeline.py`）仍可用；`techniques_loader.get_summary()` 保留（renderer 与 run_pipeline_e2e 仍在用）。
