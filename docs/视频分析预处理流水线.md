# 视频分析预处理流水线

## 改造前后对比

### 改造前

```
视频文件
  │
  ├─→ get_video_info ──→ {duration, fps, resolution}           → LLM
  ├─→ detect_scenes  ──→ [{start, end, duration}, ...]          → (丢弃)
  ├─→ 每个镜头取 1 帧 ──→ jpg                                   → LLM (vision)
  ├─→ extract_audio  ──→ wav
  └─→ transcribe     ──→ "纯文本"                               → LLM
```

**LLM 收到的**: 1 帧图片 + 纯文本 → 全靠 LLM "目测" 运动、色彩、节奏

### 改造后

```
视频文件
  │
  ├─→ get_video_info ────────────────────────────────────────── → LLM
  │
  ├─→ detect_scenes ──→ [{start, end, duration}]
  │     │
  │     ├─→ extract_multiple_frames (每镜头头/中/尾 3 帧)
  │     │     │
  │     │     ├─→ compute_shot_motion ──→ motion_intensity [0,1] → LLM
  │     │     └─→ compute_color_stats  ──→ HSV均值/标准差/主色调  → LLM
  │     │
  │     └─→ compute_rhythm_data ──→ 镜头时长/切刀频率/前3秒节奏   → LLM
  │
  ├─→ extract_audio ──→ wav
  │     │
  │     ├─→ transcribe_with_timestamps ──→ [{start, end, text}]  → LLM
  │     ├─→ detect_bpm ──────────────────→ BPM                   → LLM
  │     └─→ analyze_audio_segments ──────→ 人声/静音/音乐占比     → LLM
  │
  └─→ 每个镜头取 1 帧（中间帧） ──→ jpg (vision)                  → LLM
```

**LLM 收到的**: 1 帧图片 + 结构化数值（运动、色彩、节奏、音频特征）+ 纯文本

## 一、VideoTools 新增方法

文件: `tools/video_tools.py`

### 1.1 `extract_multiple_frames(video_path, scenes, frames_per_shot=3) -> dict`

| 项目 | 说明 |
|------|------|
| **功能** | 对每个镜头抽取多帧图像（默认头/中/尾 3 帧） |
| **输入** | `video_path`: 视频路径, `scenes`: 镜头列表, `frames_per_shot`: 每镜头帧数 |
| **输出** | `{shot_index: [frame_path1, frame_path2, ...]}` |
| **位置** | `video_tools.py:L69-L99` |
| **依赖** | OpenCV (`cv2.VideoCapture`) |

返回值示例:
```python
{
  0: ["data/temp/frame_video_s0_0.jpg", "data/temp/frame_video_s0_1.jpg", "data/temp/frame_video_s0_2.jpg"],
  1: ["data/temp/frame_video_s1_0.jpg", ...],
  ...
}
```

### 1.2 `compute_shot_motion(video_path, scene_start, scene_end, num_samples=10) -> float`

| 项目 | 说明 |
|------|------|
| **功能** | 在镜头区间内均匀采样 N 帧，计算相邻帧灰度差均值，归一化为 [0, 1] |
| **输入** | `video_path`, `scene_start`, `scene_end`, `num_samples=10` |
| **输出** | float, 0=完全静止, 1=剧烈运动 |
| **位置** | `video_tools.py:L101-L122` |
| **算法** | 采样 num_samples 帧 → 缩放到 160x90 → 灰度化 → absdiff → mean → 除以 30.0 归一化 |

### 1.3 `compute_color_stats(image_paths) -> dict`

| 项目 | 说明 |
|------|------|
| **功能** | 对一组帧计算 HSV 通道均值/标准差 + K-Means 主色调 |
| **输入** | `image_paths: list[str]` — 一个镜头的多帧图像 |
| **输出** | 字典含 hue_mean, hue_std, saturation_mean, saturation_std, value_mean, value_std, dominant_colors |
| **位置** | `video_tools.py:L124-L173` |
| **算法** | 逐帧 OpenCV BGR→HSV → 合并所有像素 → numpy 均值/标准差 → cv2.kmeans(k=3) 聚类取主色调（像素每 10 抽 1 加速） |

输出示例:
```python
{
  "hue_mean": 30.5,
  "hue_std": 15.2,
  "saturation_mean": 0.62,
  "saturation_std": 0.21,
  "value_mean": 0.73,
  "value_std": 0.15,
  "dominant_colors": ["#4A7FB5", "#2D5A27", "#8B7355"]
}
```

### 1.4 `compute_rhythm_data(scenes, total_duration) -> dict`

| 项目 | 说明 |
|------|------|
| **功能** | 从镜头切分结果计算节奏特征数据 |
| **输入** | `scenes: list[dict]`, `total_duration: float` |
| **输出** | 含 shot_count, avg_shot_duration, front_3s_cuts, cut_frequency_per_10s 等 |
| **位置** | `video_tools.py:L175-L209` |

输出示例:
```python
{
  "shot_count": 12,
  "shot_durations": [1.2, 0.8, 3.0, 0.5, 2.1, 1.5, 0.6, 1.8, 2.5, 1.0, 0.4, 1.3],
  "avg_shot_duration": 1.39,
  "min_shot_duration": 0.4,
  "max_shot_duration": 3.0,
  "std_shot_duration": 0.82,
  "front_3s_cuts": 3,
  "first_shot_duration": 1.2,
  "cut_frequency_per_10s": [5, 4, 3]
}
```

## 二、AudioTools 新增方法

文件: `tools/audio_tools.py`

### 2.1 `detect_bpm(audio_path) -> float`

| 项目 | 说明 |
|------|------|
| **功能** | 用 librosa 检测音频 BPM（每分钟节拍数） |
| **输入** | `audio_path: str` — WAV 音频路径 |
| **输出** | float, 失败时返回 0.0 |
| **位置** | `audio_tools.py:L33-L43` |
| **依赖** | `librosa>=0.10.0`（可选，缺失时返回 0.0） |
| **算法** | `librosa.load()` → `librosa.beat.beat_track()` |

### 2.2 `analyze_audio_segments(audio_path, whisper_segments=None) -> dict`

| 项目 | 说明 |
|------|------|
| **功能** | 对音频进行三分类分段：speech / silence / music |
| **输入** | `audio_path`, `whisper_segments`（可选，Whisper 带时间戳分段） |
| **输出** | 含 bpm, segments 列表, speech_ratio, silence_ratio, music_ratio |
| **位置** | `audio_tools.py:L45-L127` |
| **算法** | librosa RMS 能量 + Whisper 时间戳掩码 → 逐帧分类 → 合并连续同类型段 |

输出示例:
```python
{
  "bpm": 120.0,
  "segments": [
    {"start": 0.0, "end": 2.5, "type": "speech"},
    {"start": 2.5, "end": 3.2, "type": "silence"},
    {"start": 3.2, "end": 8.0, "type": "music"},
    {"start": 8.0, "end": 15.8, "type": "speech"}
  ],
  "speech_ratio": 0.72,
  "silence_ratio": 0.04,
  "music_ratio": 0.24
}
```

## 四、Prompt 更新

### 4.1 镜头分析 Prompt (`build_shot_analysis_prompt`)

**新增参数**: `motion_intensity`, `color_stats`

### 4.2 结构分析 Prompt (`build_structure_analysis_prompt`)

添加的 prompt 段落:

```
- 前3秒镜头数: 3 个
- 首个镜头时长: 1.2s（开场节奏）
- 第1-10秒: 5个镜头  第11-16秒: 4个镜头

【音频分析数据】
- BPM: 120.0（每分钟节拍数）
- 人声占比: 72%
- 静音占比: 4%
- 音乐占比: 24%
```

## 五、完整数据流图

```
graph/builder.py::analyst_node
│
├── 1. VideoTools.get_video_info()           → 基础元数据
├── 2. VideoTools.detect_scene_changes()     → 镜头列表
│
├── 3. VideoTools.extract_multiple_frames()  → 多帧图像
│     ├── VideoTools.compute_shot_motion()   → 每镜头运动强度
│     └── VideoTools.compute_color_stats()   → 每镜头色彩统计
│
├── 4. VideoTools.compute_rhythm_data()      → 全局节奏数据
│
├── 5. AudioTools.extract_audio()
│     ├── AudioTools.transcribe()             → 语音转写文本
│     ├── AudioTools.detect_bpm()             → BPM
│     └── AudioTools.analyze_audio_segments() → 音频分段
│
├── 6. 循环每个镜头:
│      AnalystAgent._analyze_frame(
│        video_path, scene_time,
│        motion_intensity, color_stats,     ← 预处理数据
│        prev_frame_desc
│      )
│      → LLM 返回: content, technique, structure_role, emotion
│
└── 7. AnalystAgent._analyze_structure(
        shot_analyses_text,
        transcript,
        rhythm_data, audio_data,            ← 预处理数据
      )
      → LLM 返回: script_structure, rhythm_analysis,
                   packaging_analysis, hook_strategy, ...

8. AnalystAgent.build_video_structure()
   → VideoStructure (包含 ShotInfo 列表，每条含 motion_intensity, color_stats)
```
