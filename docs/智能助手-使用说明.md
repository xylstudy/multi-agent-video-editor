# Video Claw 智能助手

## 入口

登录后打开左侧的“智能助手”，或在项目详情、任务详情页点击“智能助手”。从详情页进入时，助手会自动带上当前项目/任务上下文。

## 可以直接说什么

| 目的 | 示例 |
| --- | --- |
| 查询项目、任务、视频基因、知识库、成片 | “列出我的项目”“看看最近任务进度”“我的知识库有多少条” |
| 查看统计和洞察 | “查看统计洞察” |
| 创建项目 | “创建一个城市夜游项目” |
| 启动视频分析 | “分析当前项目的参考视频” |
| 启动素材分析 | “分析当前项目的照片素材” |
| 生成完整方案 | “生成分镜方案” |
| 查看/确认分镜 | “打开分镜方案”“确认分镜并开始渲染” |
| 提炼知识 | “从这个视频基因提炼知识” |

## 上传素材后执行

在输入框左侧点击回形针上传视频、图片或音频，再用文字说明下一步。上传的文件只属于当前账号和当前会话：

- 上传参考视频并说“分析这个视频”会创建视频基因并启动后台分析。
- 在项目上下文中上传素材并启动任务，会自动将附件导入项目素材库。
- 附件大小限制为单个 500 MB，支持常见的视频、图片和音频格式。

## 安全规则

- 助手只能调用系统内置的白名单动作，不会执行模型生成的 shell、Python 或任意 URL。
- 项目、任务、基因和附件都会校验当前用户归属。
- 分镜渲染仍需要明确的“确认”指令；删除类操作不由助手直接执行。
- 每条会话消息和动作都会留在会话记录中，便于追踪失败原因。

## 接口

- `GET/POST /api/chat/sessions`
- `GET/POST /api/chat/sessions/{session_id}/messages`
- `POST /api/chat/sessions/{session_id}/attachments`

复杂指令由设置页配置的文本模型负责规划；视频和图片分析仍使用系统的视觉模型，不需要新增第三套 API。
