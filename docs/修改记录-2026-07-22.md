## 四、排障备忘

- SQLAlchemy Enum 列库存的是**枚举名**（`DONE`），不是值（`done`）；手工 sqlite 修数时用错会导致读取 500（`LookupError: 'done' is not among the defined enum values`）。
- Windows Git Bash 下 `curl -F` 提交中文表单会按 GBK 编码导致标题乱码；验证脚本改用 Python urllib 手工拼 multipart。
- Git Bash 的 `/tmp` 只有 MSYS 程序（bash/cat）能解析，Windows 原生 curl/python 不认识，避免跨程序传文件路径。

## 五、追加修复：基因列表 500（用户反馈"提取没反应"）

### 现象与根因

用户上传视频点击提取后页面"没反应"，但工作台基因数量增加。根因：迁移加列后**存量行 `progress_logs` 为 NULL**（SQLite `ALTER TABLE ADD COLUMN` 不带默认值的列，旧行读作 NULL），`GeneRead.progress_logs: list` 校验失败 → `GET /api/genes` 整列 500 → 前端 `fetchGenes` 拿不到新数据，看起来像没反应。POST 创建本身成功，所以工作台数量照常 +1（该接口不走 GeneRead）。E2E 验证时用的 playtest 账号没有旧记录，所以没暴露。

### 修复

- `database.py`：迁移追加回填 `UPDATE gene SET progress_logs='[]' / progress=0 WHERE ... IS NULL`
- `db_models.py`：`GeneRead` 加 `field_validator(mode="before")`，NULL 兜底为 `[]` / `0`，防止任何存量 NULL 再次整列 500

验证：5 条基因（含旧记录 id=1）全部通过 GeneRead 校验，旧记录已回填。

## 六、追加改动（晚间）：知识库演示教学化重写（第二部分）

### 背景

07-20 已把 23 条转场演示教学化（放慢转场 + 教学时间轴）。本次把剩余演示类型全部改成同一套教学语言——目标仍是"教学优先，不是成片示例"：每个演示都要讲清三件事：被演示的对象是谁、动作发生在哪、当前播到时间轴哪一段。

### 改动（`remotion/src/TechniqueDemo.tsx`，生产组件零改动）

- **reveal（7 种前景揭示）**：前景加发光轮廓（drop-shadow）标出被揭示对象；右上角「背景/前景」阶段角标；揭示动作放慢到 30 帧，按「背景 15f → 揭示 30f → 合成 15f」循环 2 次；底部时间轴同步标注。时长 80→120
- **subtitle（8 种字幕样式）**：示例文案固定为「示例字幕 ABC123」，与顶部技法名标签分离（谁是被演示对象一目了然）；75f 循环 2 次，typewriter 等慢动画也能看全。时长 75→150
- **effect（胶片颗粒 ×2 / 变速 ×2 / 运动模糊 / 强化甩镜头）**：改为前后对比结构——前半原片（灰「原片」角标）→ 后半特效（蓝「特效」角标），同机位素材直接对比；变速加「匀速/变速」双进度条，把不可见的时间重映射画出来；运动模糊/甩镜头加运动方向箭头；颗粒强度从生产值 0.18 提到 0.3+（540×960 下 0.18 不易察觉）。时长 80→90
- **packaging（3 种包装风格）**：左下固定「风格配方」清单（这条风格 = 哪些转场 + 哪种字幕 + 多少颗粒）；转场窗口内弹出转场名标签（TransitionPopup），风格差异不再靠悟；底部场景链时间轴。场景段 36f→44f。时长 94→116
- **montage / emotion_arc**：补教学时间轴（画面内容不变，时长不变）
- **variety**：转场标签换用 TransitionPopup（只在转场窗口内显示，不再常驻）；补全链时间轴；节奏放慢（场景 28f→40f，转场重叠 12f→14f）。时长 104→158
- **beat**：保持原设计（节拍指示点本身已具备教学性）
- 新增共享组件：`PhaseBadge`（阶段角标）、`DirectionArrow`（运动方向箭头）、`RampBars`（匀速/变速双进度条）、`TransitionPopup`（转场名弹标）；`TransitionTimeline` 复用到全部演示类型
- 内部重构：`SpeedRampPhoto`/`MotionBlurPhoto`/`WhipPanPhoto` 由 `useCurrentFrame` 自读帧改为接收 `f`/`duration` props，供前后半段复用；新增 `LinearZoomPhoto`/`SlidePhoto`/`PanPhoto` 匀速对照组
- `getDemoDuration` 同步更新（reveal 120 / subtitle 150 / effect 90 / packaging 116 / variety 158），`Root.tsx` 的 `calculateMetadata` 自动生效，无需改动
