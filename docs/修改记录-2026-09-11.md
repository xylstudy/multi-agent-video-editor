## 3. 生成链路的用户知识隔离

- 多智能体生成任务会从共享 JSON 中筛出当前用户拥有的知识，写入任务目录下的 `personal_knowledge.json`。
- 子进程只读取该任务级文件，并将最近 20 条个人知识加入方案生成偏好。
- 系统内置能力继续生效；其他用户的个人知识不会进入当前任务。

## 5. 统计洞察重构

- 修复新账号会混入全局 `data/output` 历史报告的问题；默认 `scope=mine` 只扫描当前用户的 `genes/`。
- 删除无原视频、无正式元数据的历史 `data/output/analysis_result.json`，并取消“系统样例”概念。
- `GET /api/insights` 只扫描当前账号的基因报告，不再提供全局数据 scope。
- 修复 Web 基因产物使用 `report.json`、扫描器却只识别 `analysis_result.json` 的格式遗漏。
- 按标准化报告内容生成指纹去重，避免同一分析的副本被重复计数。
- JSON 接口不再为 iframe 重复生成 HTML，也不再返回报告和素材的本机绝对路径。
- 前端移除固定高度白色 iframe，重做为原生深色统计卡、分布条形图、镜头时间线、情绪流和镜头详情面板。

- 新增洞察 scope、响应脱敏、`report.json` 识别和内容去重测试。

## 6. 设置页升级为模型管理

- 参考 TRAE / WorkBuddy 的模型管理方式，将原来的“按服务商保存 API Key”改为完整的账号级模型配置。
- 新增智谱、DeepSeek、Moonshot、OpenAI 兼容和自定义服务入口；支持展示名称、模型 ID、Base URL / 完整请求 URL、API Key、图片输入能力。
- 当前引擎明确只开放 OpenAI Chat Completions 兼容格式；尚未实现的 Anthropic Messages 不提供虚假选项。
- 支持连接测试、编辑、启用/停用、删除，并可分别指定“视觉分析”和“方案生成”默认模型。
- 模型查询接口只返回密钥掩码与是否已配置，不返回原始 API Key；数据库使用本地 Fernet 主钥匙加密保存密钥。
- 本地加密主钥匙位于 `.local/model_api_keys.key`（已被 Git 忽略）；迁移机器时需与数据库一并备份，否则旧密钥无法解密。
- 旧设置页保存的智谱、DeepSeek、Moonshot Key 会在启动时自动迁移为模型配置；旧接口继续保留兼容。

## 7. 模型配置接入实际任务
