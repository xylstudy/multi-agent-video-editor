# Hook（开场抓注意力）

## 适用条件

- 规划第一个镜头 / 前 3 秒。
- Gene 要求 `function = hook`（critical 约束）。
- 平台完播率敏感（抖音/小红书竖屏 Vlog）。

## 不适用条件 / caution

- **不要**为了 Hook 牺牲 Gene 的 `establishing` 硬约束：如果 Gene 第 1 镜是场景建立，
  先满足"让观众知道这是哪"，再叠加抓眼球手法。
- 用户素材没有任何冲击性画面时，不要硬造"假悬念"（最怕刻意）。

## 推荐策略

- **结果前置 / 悬念提问 / 金句开头 / 视觉冲击** 四选一，与用户素材强相关。
- 用画面自身的信息密度抓人：地标、人物、冲突、反差。
- 前 3 秒节奏快：单镜 ≤ 2.5s，多用 `zoom_heavy` / `whip` / `flash_white`。
- 若素材偏静态，用大字幕 + 逐词高亮（`wordHighlight`）补足信息冲击。

## 例子 / 来源

- 来源：11 条抖音旅行爆款，前 3 秒平均镜头数高、多为视觉冲击或地标空镜开场。
- 反例：前 3 秒放纯文字卡且无任何画面信息 → 观众直接划走。
