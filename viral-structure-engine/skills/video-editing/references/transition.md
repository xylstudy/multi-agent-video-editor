# Transition（转场）

## 适用条件

- 需要为某个分镜选 `transition_in`。
- Gene 指定了段落节奏（快/中/慢）或情绪时。

## 不适用条件 / caution

- 转场是"情绪放大器"，不是"炫技清单"——不要为多样性硬上 glitch/freeze_frame 破坏情绪。
- 相邻分镜转场不要完全相同；cut 占比不宜超过 50%。

## 推荐策略（按场景，非按清单）

| 场景 / 情绪 | 推荐转场 | 避免 |
|---|---|---|
| Hook / 冲击 | zoom_heavy / whip / flash_white | dissolve / fade |
| 场景建立 | fade / blur_in / zoom_out / slide | glitch / freeze_frame |
| 情绪高潮 | zoom_flash / zoom_heavy / whip / spin | dissolve / fade |
| 日常叙述 | cut / slide / fade / zoom_in | glitch |
| 收尾 | fade / dissolve / blur_in / flash_black | glitch / zoom_heavy |

- 节奏快 → 密集 cut/whip/flash；节奏慢 → 稀疏 fade/dissolve/blur_in。
- 转场要与所在段落的音频能量匹配（能量高用冲击转场，能量低用柔和转场）。

## 例子 / 来源

- 来源：`editing_techniques.json` 中 20 种转场的适用性分析，以及镜头类型→转场映射。
- 反例：温馨治愈段落用了 glitch → 情绪断裂。
