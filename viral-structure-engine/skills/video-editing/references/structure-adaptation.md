# Structure Adaptation（结构适配）

## 适用条件

- 原结构在用户素材条件下无法 1:1 落地（素材数量不足、缺某类功能画面、时长不匹配）。
- 需要把 Gene 的骨架"变形"到可执行，同时保住核心功能。

## 不适用条件 / caution

- **只能改自由度，不能改硬约束**：Hook 结构、高潮/Ending 位置、核心镜头功能属于 Gene 硬约束，
  不可因 Skill 建议而放弃。
- 适配要"可解释"：记录为什么变形，供 Reviewer 判断是否合理。

## 推荐策略

- **保功能、换载体**：establishing 无航拍 → 用宽景/地标照替代；climax 无视频 → 用最强照片 + 强运镜。
- **合并/拆分镜头**：素材不足时，多图拼贴（layers）合并到一镜；素材富余时，把 daily_moment 拆成多镜。
- **时长重分配**：保持 `climax_position_ratio` 大致位置，但允许各段按素材量微调时长。
- 适配结果写进 `adaptation` 字段（preserved / reason / original_function）。

## 例子 / 来源

- 来源：结构迁移实践中"骨架可迁移、内容必须本地化"的通用原则。
- 反例：用户没有夜景素材，仍硬塞"夜景高潮"→ 素材违和，Reviewer 判"剪得不好"。
