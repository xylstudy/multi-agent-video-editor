# Subtitle / Packaging（字幕与包装）

## 适用条件

- 需要为分镜配 `subtitle_text` / `subtitle_config`，或统一包装风格。
- Gene 给出 `packaging`（字幕位置/动画/调色）或 `info` 镜头功能时。

## 不适用条件 / caution

- 字幕是完播率基础设施，叙事段必须有字幕；纯音乐段可无。
- 相邻分镜字幕配置要做差异化，不能全程同字号/同位置/同颜色。

## 推荐策略

- **差异化**：开场/信息卡用大字号（56-72）+ center；叙述段用标准（36-42）+ bottom；高潮用醒目色 + scale_up。
- 文字卡简洁易读，不遮挡关键画面（关键主体避开字幕区）。
- 统一调色风格（color_grade）贯穿全片，避免风格漂移。

## 例子 / 来源

- 来源：8 种子幕样式 + 3 种风格预设（快速电子 / 电影氛围 / 创意混合）。
- 反例：全程同款字幕无动画 → 平淡；字幕盖住人脸 → 信息损失。
