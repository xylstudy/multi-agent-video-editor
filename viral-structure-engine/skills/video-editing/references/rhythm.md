# Rhythm（节奏）

## 适用条件

- 需要决定每个分镜的时长、快慢交替、切点位置。
- Gene 给出 `rhythm_role`（fast_cut / breather / build_up / climax / resolve）或 `rhythm_pattern`。

## 不适用条件 / caution

- 不要全程快切也不要全程慢——需要"呼吸感"。
- Gene 有明确 `climax_position_ratio` 时，高潮位置要大致对齐，不要随意挪动。

## 推荐策略

- **BPM → 分镜时长**：BPM>120 → 2-3s；90-120 → 3-4s；<90 → 4-6s。
- **节奏弧**：开场快 → 中段呼吸 → 高潮爆点 → 收尾放缓。
- **卡点**：在节拍点/关键转场点切镜；相邻镜头 motion 方向交替（zoom_in/zoom_out/pan 交替）。
- Ken Burns 速度：短镜 fast、中镜 medium、长镜 slow。

## 例子 / 来源

- 来源：爆款后 1/3 段通常较前段加速；高潮点对应 BGM drop 处切镜。
- 反例：全程 3s 硬切无变化 → 视觉疲劳，无记忆点。
